# Anvi Gupta — portfolio

Plain HTML and CSS, no build step.

- `index.html` — home page
- `projects/safeshare.html`, `projects/mythtrace.html` — case studies
- `styles.css` — shared styles (colours and fonts are at the top)
- `assets/` — images and favicon

To preview: open `index.html` in a browser.
To deploy: import this repo at vercel.com/new (framework preset: Other, no build command).
